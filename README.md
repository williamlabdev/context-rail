# ContextRail Prototype Workspace

This workspace contains the ContextRail product and planning material. The reusable Project Context Contract template is [template/](template/README.md); the first governed example Project is [Order Operations Portal](demo/order-operations-portal/README.md).

The demo is deliberately a separate Project fixture: it contains its own Context Contract documents, Go application, Request, DecisionRecord, engineering evidence and Cloud Run staging receipt. Production is represented as a protected decision threshold and is not deployed.
